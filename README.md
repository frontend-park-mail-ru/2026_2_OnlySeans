# 2026_2_OnlySeans

### Локальный запуск и сборка

- `npm ci` — установить зависимости из lock-файла.
- `npm run dev` — запустить Webpack Dev Server на `http://localhost:3000`.
- `npm run build` — проверить TypeScript и собрать приложение через Babel и Webpack в `dist/`.
- `npm start` — после сборки открыть приложение на `http://localhost:8000`. Сервер раздаёт `dist/` и пересылает запросы к API на `http://127.0.0.1:8080`. Порт можно задать через `PORT`, адрес бэкенда — через `API_PROXY_TARGET`.
- `npm run test:offline` — проверить сборку, service worker и отправку изменений после подключения к сети.

PostCSS работает до `css-loader`. В исходниках `@media (--reduced-motion)` и `@media (--short-auth)` используются как общие условия. На этапе сборки они превращаются в стандартные медиа-запросы.

### Проверка офлайн-режима

1. Запустите бэкенд и production-сборку фронтенда. Войдите, откройте каталог, фильм, актёра и профиль. Дождитесь загрузки данных. Service worker включён для production-сборки на HTTPS и localhost.
2. В инструментах разработчика переключите сеть в режим Offline. Обновите страницу и перейдите по уже открывавшимся маршрутам. Приложение возьмёт HTML, CSS, JavaScript и ранее загруженные данные из кеша.
3. Поставьте оценку или сохраните отзыв офлайн, затем верните сеть. Изменения будут отправлены для того же аккаунта. Если серверная версия отзыва изменилась, локальный текст останется доступен в форме.
4. Вход, регистрация, выход и изменение данных профиля требуют связи с API. Внешние изображения и шрифты зависят от кеша браузера. При смене аккаунта или выходе персональный кеш и очередь предыдущего аккаунта очищаются.
