# 2026_2_OnlySeans

### Локальный запуск и сборка

- `npm ci` — установить зависимости из lock-файла.
- `npm run dev` — запустить Webpack Dev Server на `http://localhost:3000`.
- `npm run build` — проверить TypeScript и собрать приложение через Babel и Webpack в `dist/`.
- `npm start` — после сборки открыть приложение на `http://localhost:8000`. Сервер раздаёт `dist/` и пересылает запросы к API на `http://127.0.0.1:8080`. Порт можно задать через `PORT`, адрес бэкенда — через `API_PROXY_TARGET`.
- `npm run test:offline` — проверить сборку, service worker и отправку изменений после подключения к сети.

PostCSS работает до `css-loader`. В исходниках `@media (--reduced-motion)` и `@media (--short-auth)` используются как общие условия. На этапе сборки они превращаются в стандартные медиа-запросы.

### Проверка офлайн-режима

1. Запустите бэкенд и production-сборку фронтенда. Войдите, откройте каталог, фильм, актёра и профиль. Дождитесь загрузки данных. Service worker включён для production-сборки на HTTPS и localhost.
2. В инструментах разработчика переключите сеть в режим Offline. Обновите страницу и перейдите по уже открывавшимся маршрутам. Приложение возьмёт HTML, CSS, JavaScript и ранее загруженные данные из кеша.
3. Поставьте оценку или сохраните отзыв офлайн, затем верните сеть. Изменения будут отправлены для того же аккаунта. Если серверная версия отзыва изменилась, локальный текст останется доступен в форме.
4. Вход, регистрация, выход и изменение данных профиля требуют связи с API. Внешние изображения и шрифты зависят от кеша браузера. При смене аккаунта или выходе персональный кеш и очередь предыдущего аккаунта очищаются.

### OnlineConf

- Админка доступна по `/onlineconf/`. Для входа используется учётная запись Frame с правами администратора.
- `npm run dev` и `npm start` направляют `/api/onlineconf/admin/*` на `ONLINECONF_PROXY_TARGET` (по умолчанию `http://127.0.0.1:8081`). Остальные API, включая `/api/onlineconf/runtime`, обслуживает `API_PROXY_TARGET`.
- На стенде вложенные маршруты `/onlineconf/…` должны возвращать `dist/onlineconf/index.html`. Статика админки находится под `/assets/onlineconf/`. У этих файлов и API нет HTML fallback.
- После восстановления сессии продукт получает `GET /api/onlineconf/runtime` с cookie текущего пользователя. В открытой активной вкладке один клиент обновляет настройки каждые 15 секунд. Форма фильма и кнопка «О фильме» подписаны на одно состояние.
- Для отзывов нужны целое `configs["reviews.max_length"]` от 50 до 20000 и логическое `flags["reviews.write_enabled"]`. Заголовок содержит от 3 до 255 символов Unicode после удаления крайних пробелов. Лимит OnlineConf применяется к тексту отзыва.
- В контракте продуктового Go API `revision: 0` обозначает пустой кеш при старте. Форма сохраняет черновик и блокирует отправку. Положительная ревизия восстанавливает работу, когда догоняет последнюю принятую версию этого аккаунта.
- После `403 feature_disabled` форма блокирует публикацию. Старое разрешение из той же или более ранней ревизии не открывает кнопку. После `400 review_too_long` счётчик сразу учитывает `details.max_length`. Оба ответа вызывают внеочередное обновление.
- Цвет кнопки использует необязательные поля `configs["frontend.watch_button_theme"]` (`"amber"` или `"wine"`) и `flags["frontend.watch_button_theme_enabled"]`. При их отсутствии кнопка использует обычное оформление.

#### Проверка на стенде

1. Откройте один фильм в двух профилях браузера. При включённом флаге и rollout 0% добавьте A в список принудительного включения. Проверьте доступную кнопку у A и причину запрета у B. Затем задайте 100%, исключите B и повторите проверку. Для промежуточного процента уберите персональные правила A и B и сравните обе формы с результатом проверки пользователя в админке.
2. При разрешённой записи введите заголовок и 150 символов текста. Уменьшите лимит с 500 до 100. Измерьте время от подтверждения сохранения в админке до появления `150 / 100` и заблокированной кнопки. Требование — не более 60 секунд. Верните 500 и проверьте текст и выделение.
3. В Network проверьте один периодический запрос за 15 секунд в активной вкладке. Переключите аккаунт при незавершённом запросе. Проверьте восстановление сети с офлайн-черновиком и блокировку во время холодного старта API.
